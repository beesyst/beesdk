# BeeSDK final review

Use this skill for one complete read-only review of an approved BeeSDK Issue against its declared base branch.

Read `AGENTS.md`, the Issue, `docs/ROADMAP.md`, `docs/SDLC.md`, `docs/SECURITY.md`, the Issue/PR templates, the complete diff and changed-file contents. Inspect public API, compatibility, dependency direction, authority boundary, documentation and verification evidence. Do not modify files or run commands.

Return one consolidated verdict: `APPROVE`, `CHANGES REQUIRED` or `REVIEW INCOMPLETE`. Block only unmet acceptance criteria, unsafe or incompatible public contracts, dependency-direction violations, unreviewed runtime dependencies, missing required verification or out-of-scope changes.
