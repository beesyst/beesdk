# BeeSDK planning

Use this skill to assess a BeeSDK roadmap item or standalone task before implementation.

Read `AGENTS.md`, `docs/ROADMAP.md`, `docs/SPEC.md`, `docs/ARCHITECTURE.md`, `docs/SDLC.md`, `docs/SECURITY.md` and the Issue template. Inspect the current BeeSDK worktree before proposing scope. Read a consumer project only when the task explicitly concerns that consumer.

Return a compact Russian task statement, a complete English Issue based on `.github/ISSUE_TEMPLATE/issue.md`, recommended branch/Conventional Commit and task-specific constraints. Classify public API, authority/capability boundary or runtime dependency changes as security-sensitive. Do not modify files during planning.
