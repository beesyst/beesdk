# BeeSDK roadmap

## Stage 1 — Contract foundation

### Iteration SDK-1 — repository and core contract foundation v0.1.0

**Status: IN PROGRESS**

Scope:

- standalone repository;
- packaging;
- governance and documentation;
- public module contracts;
- `ArtifactPort`;
- `CapabilityCaller`, result and status;
- tests;
- zero runtime dependencies;
- package build.

Excluded:

- BeeAgent adoption;
- ROP adoption;
- BeeScan implementation;
- capability runtime/gateway implementation;
- state;
- configuration implementation;
- execution or egress.

## Planned orientation

- SDK-2 — contract validation through BeeAgent/ROP adoption.
- SDK-3 — scoped capability contract evolution, only after real integration evidence.
- SDK-4 — project/state contracts, only when required by actual consumers.

These items are orientation, not pre-approved design scope.
